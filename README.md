# 今朝 · Good day

一个关于情绪、生活与当下状态的小工具。

## 关于

「今朝 · Good day」希望帮助人们认识自己的情绪，理解自己的状态，并在需要的时候尝试一些简单、具体的小行动。

情绪会影响我们的注意、记忆、判断和日常行动。了解自己的情绪，也是了解自己的一种方式。

这里会通过简短的内容、情绪知识和生活中的小方法，让一些容易被忽略的感受重新被看见。

不需要完成复杂的任务。

有时候，只需要停下来，看一张卡片，了解一种情绪，或者尝试一个很小的行动。

## 设计理念

我希望这个工具保持轻盈、简单和容易进入日常生活。

它不试图替用户安排生活，也不提供所谓的标准答案。

它只是提供一些关于情绪与生活的观察，以及一些可以随时尝试的小方法。

也许某一个方法刚好会对你有帮助。

也许它只是让你在忙碌的一天里停下来几十秒。

这就已经足够。

## 名字

中文名：**今朝**

英文名：**Good day**

希望你今天度过开心的一天。

**无论如何，今天都是很好的一天。**
