# 今朝 · My Day — Vibecoding 工具

> 一个抽卡形式的小工具，点开就有「今日不焦虑处方」。
> 英文名 How's your day? · 中文名「今朝 · My Day」——今日之择，即是天意。
> 目标赛道：**#vibetool**（实用工具，让生活/工作变简单）。

## 快速开始

```bash
# 1. 本地预览
cd good-day
python3 -m http.server 8788 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8788

# 2. 或直接双击 index.html，浏览器里也能跑（单文件、零依赖）
```

整个项目就一个 `index.html`（+ 本地 `html2canvas.min.js`），自包含、纯前端、可离线。

## 核心交互

1. **选择情绪** — 首页 6 个情绪泡泡（开心/沮丧/伤心/平静/随机/赞美），按情绪推荐对应卡片
2. **抽一张卡** — 点击情绪或点击魔法棒 → 叩击水面涟漪 → 翻牌 → 看到卡片
3. **复制文字** — 一键复制成可直接发小红书的格式（含日期天气、主题句、直译、释义、出处、品牌）
4. **保存图片** — 生成高清卡片图（竖版风格，无按钮 UI）
5. **再看一眼** — 重新抽一张；点击卡片空白处可返回首页重新选情绪

## 技术要点

- 智能断行：中文按句末标点/虚词断句，英文按子句断（单词不拆），括号整体不拆；`inline-block` 保证短句不孤行、无孤立符号占行
- 时间感知：日期 + 天气自动生成（白天/夜间图标切换），支持 localStorage 手动设置温度
- 卡片比例：280×520（小屏 250×480），下载图高清无按钮
- 主题词统一 34px，中文深紫、外文银白光泽，英文用 Georgia italic、中文用 skewX(-8deg) 强制斜体
- 情绪泡泡漂浮在卡面上（absolute 居中），气泡感样式（渐变半透明+内发光+外阴影）
- 删除金钱直接相关签文（富兰克林/量入为出/君子爱财/韩文티끌），丰盛心态改归 selfcare
- 行业签去傲慢措辞（如「常开车的都懂」→「开车遇到红灯」），全部补英文翻译
- 版权安全：古诗/成语/谚语等公有领域内容为主，不照搬受版权保护的现代书籍

## 设计取向

- 淡紫色治愈风（#7A5FC0）—— 极简、留白、杂志感
- 每条签文都被打磨过——不喊口号、不催泪、不灌鸡汤
- 卡片全正向——抽到什么卡都不是坏卡
- 无广告、无追踪、localStorage 本地记忆
